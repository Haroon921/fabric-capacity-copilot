# Contributing

Thank you for helping improve Fabric Capacity Copilot.

## Before you start

1. Review the open issues and roadmap.
2. Open an issue for significant behavior or architecture changes.
3. Never include tenant telemetry, credentials, or other sensitive information.

## Development workflow

```bash
npm ci
npm run dev
```

Create a focused branch, keep changes scoped to one outcome, and validate the production build:

```bash
npm run build
```

## Pull requests

- Explain the user or operational outcome.
- Add or update documentation for behavior changes.
- Include screenshots for visual changes.
- Preserve the sample-data disclosure in all demonstrations.
- Confirm that the change does not introduce secrets or tenant data.
